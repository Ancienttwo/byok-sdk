# Plan: upgrade the private OAR Codex source from 0.29.0 to 0.33.1

Status: owner direction on 2026-10-07: simplify, follow OAR. Not yet executed.
Research input: `docs/researches/2026-10-07-oar-029-to-0331.md`.

## Rule

Follow OAR. Take the upstream bytes. Add no new BYOK delta except where the
SDK ES2022 lib requires it. Where BYOK has its own mechanism and OAR has one
for the same job, use the OAR one and delete ours.

## Target

- Vendor `v0.33.1` (`e1f91770a7edbaf4521f570345f2e8d0c998d238`) to
  `packages/client/vendor/oar/e1f9177`.
- Codex task MCP servers use OAR `SessionOptions.mcpServers`. The BYOK
  `mcp-env` helper is deleted.
- Pi disposal waits up to 10 s for shutdown hooks, as OAR does.

Not in scope: other OAR runtimes, the OAR process manager, the observe API
(`redactRecord`, `REDACTION_RULES`), and the BYOK Codex usage projection
(it reads native frames, so the 0.30 resume fix does not change billing).
