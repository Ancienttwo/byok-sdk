## Goal
Make pi a required, exact core dependency; raise the dispatch runtime floor to Node 22.19; cut the RPC completion contract from agent_end to agent_settled; preserve pnpm support and define Bun as package-manager/packager only while pi executes as a Node sidecar. Release the dispatch graph as 0.2.0 while keeping the independent keys package at 0.1.0 / Node 20.
