## Owner decisions (2026-09-24/25)

- Freeze the fork. P0 shipped on fork 0.86.1001 as SDK 0.21.0; this is the next, separate work-package. It does not wait for upstream.
- **A1'' approved (2026-09-25, supersedes sink A1').** Compile with the real model baseUrl through official `streamSimple`; endpoint-dependent compat/cache semantics remain upstream-owned.
  - Only a placeholder apiKey; no real credentials or transport configuration during compile.
  - Capture fetch must be called exactly once and always throw. Zero/multiple calls fail closed without D.
  - Pin every official package exactly. An upgrade-blocking conformance test checks that injected fetch receives the expected URL and exact body, including the OpenAI cache case.
  - Residual risk: if upstream ignores the injected fetch and conformance also misses that regression, a placeholder-key request could reach the intended provider. Owner accepted this risk on the stated assumption that it is refused without billing; no claim of live provider verification is made.
  - Replace capture with a public builder when available; U1 remains earendil-works/pi#10001.
- **U2 ruling (2026-09-25).** Host supplies one required verbatim `systemPrompt`. Remove all Pi renderer inputs in a single wire/record cutover. No Session allocation during compile, no copied renderer, no Pi default prompt or device-local cwd/skills/docs in D. Tool declarations use only the observed tools parameter. Salesko prompt assembly is a subsequent Host change.
- **A2' approved.** Host-authored assistant history carries request-local sentinel provenance.
  - The sentinel exists only in the compile input and in the `context_with_system` return value.
  - It is never persisted.
  - Text blocks only.
  - Conformance must prove it is wire-neutral: `transform-messages.ts:96-98` and the assistant branch of `convertMessages` do not read provenance, and `compaction.ts:174` skips zero usage.
- **Final-send gate.** `ModelRuntime.registerProvider({streamSimple})` plus `ProviderRequestOptions.fetch` compares the serialized body byte-for-byte with D. On drift it sends nothing and returns a typed refusal. The refusal code is recorded inside the gate closure, because upstream only surfaces "Connection error.".
- C02 Amendment 2 Errata 1 (Salesko, sha256 af5efa27…) moves "empty `requiredToolsets`" into this package.

## Invariants

- No private deep imports, no patch-package or post-install patch, no copied serializer or session core, no global network monkey-patch. Only public exports: coding-agent `.`/`./rpc-entry`/`./client`/`./experimental/plugin`, and pi-ai `.`/`./api/*`/`./utils/*`/`./compat`.
- One authority. No fork/official dual runtime, no alias of both. At merge, the active dependency graph contains zero `@byok-sdk/pi-*`.
- Every prepared-lane guarantee from 0.21.0 still holds:
  - the bytes sent equal D;
  - the usage check runs before the body;
  - the `context_overflow` and `usage_unavailable` typed failures;
  - zero native tools under `auto` with `[]`;
  - the pre-pin native check;
  - egress sanitization.
- Pin exact versions: official `@earendil-works/pi-coding-agent@0.87.1`, `pi-ai`, `pi-agent-core`, and the five sibling packages (chord, pi-agent-core, pi-ai, pi-telemetry, pi-tui) whose shrinkwrap entries lack integrity.
- The runtime identity changes, so the Salesko ruling must be re-issued as a new revision and C re-probed on the official closure (see M5). No C value may be carried over from the fork.
