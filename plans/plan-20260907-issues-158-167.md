  durability → disposal receipt → lease release. Control messages use the same
  receive path. Codex argv/stdout and artifact fd reads precede event budgets.

  pending operations and uncommitted bytes are the first pressure points; never
  pretend timeout proves quiescence or a failed write proves acknowledgement.
