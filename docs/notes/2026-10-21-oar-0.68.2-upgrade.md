# OAR 0.68.2 upgrade

## P1: Boundary

OAR is selected SDK-owned source, not an npm dependency. The fork includes
the Codex session, shared ACP stack, Grok session and process-tree helpers.
The JS bridges and provenance build step select the fork directory.

## P2: Runtime path

CodexAdapter starts the private codex-session-runtime bridge. The bridge loads
the vendored codexSession. BYOK supplies the process and filtered environment.
GrokAdapter loads the private ACP bridge. The upstream ACP profile opens or
resumes the agent session with a bounded request.

## P3: Decision and plan

1. Verify upstream tag v0.68.2 and compare every selected source file.
2. Move the fork to 60ad09b. Keep the nine BYOK process, environment,
   deadline, record-budget and interaction deltas.
3. Update bridges, source hashes, build assets and current source references.
4. Run the five root checks and the bridge tests.

The tag resolves to commit 60ad09b9b97bdd005360504fda2de0d59826f08c.

changed. Two contract files change comments. shared/acp/profile.ts adds
sessionStartTimeoutMs for session/new and session/resume. Grok leaves it
unset, so its existing timeout stays in effect. No maintained file changed
upstream. The selected inventory and npm dependencies stay the same.
