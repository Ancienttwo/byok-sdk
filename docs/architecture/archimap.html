The device daemon remainder is a two-way import hub

client-daemon holds 68.0k LOC in 375 files. It imports and is imported by every client component: execution 164 / 42, service 96 / 20, Agent home 18 / 34, session 12 / 34. No component builds or tests without it. Direction: continue the client layering and the TaskRunner reducer split in #1099.
