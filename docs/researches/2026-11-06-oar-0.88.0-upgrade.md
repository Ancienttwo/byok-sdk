# OAR 0.88.0 selected-source upgrade

## Scope and trace

upstream v0.88.0 tag (`be46fb3615a4de38e4004556c2b3a1a4860f72e6`). OAR remains
selected SDK-owned source, not an npm dependency. Tracking issue: #1469.

paths between the two tags (24 commits, +417/-213) and deleted none. The
closure gains `shared/record-retention.ts`, `shared/same-directory.ts`,
`shared/acp/config-updates.ts` and `runtimes/grok/compaction.ts`, for 99 source
files plus LICENSE. 83 keep upstream bytes and the same 16 carry BYOK changes.

## Behaviour that reaches the SDK

The SDK sees vendored sessions through narrowed bridges. `queue`, `withdraw`,
`compact` and ACP `steer` stay named omissions.

| Upstream change | Effect on the SDK |
| --- | --- |
| #614 Codex busy gate released before the `turn_ended` frame | Internal: SDK adapters do not prompt synchronously from `onRecord` |
| #614 ACP adapter-held queue, `prompt` with `carries` | Internal: the bridge has no `queue` |
| #614 Grok `compact` | Internal: not bridged, launch profile unchanged |
| #622 resume cwd fails closed without `session/list` | Internal for Grok and dsh: only `resumeKeepsSessionCwd` profiles are affected |
| #627 refused `thread/name/set` keeps the session open | Internal: the bridge options have no `name` |
| #627 missing cwd error | Error text only: "Codex session directory does not exist" instead of ENOENT with the executable's name |
| #629 `serverRequest/resolved` derives no `app_request_cancelled` | One test expectation: `adapters/codex/native-interactions.ts` reads the native notification |
| #630 `retainedBytes` | Omitted: the fork's session options do not accept it and the adapters own the budget |
| #633 `endTurnProcessesOnAbort` | Omitted, see below |

The nine API-surface goldens are unchanged. Closure budgets grow, most on
`#byok-acp-runtime` (80852 to 92601 bytes), which takes the queue, compaction
and config-update code.

## Omissions

#633 ends an aborted turn's processes while the session stays usable. It needs
`LineProcess.observeCancellation`, the asynchronous process-table reader and
the turn-scope modules of the executable manager, which the fork does not
vendor. An aborted Codex turn's detached commands therefore live until session
dispose, when the SDK process-tree authority kills them.

#629 `runtimes/codex/runtime-requests.ts` is not taken: the BYOK server-request
lifecycle stays the authority.

`runtimes/dsh` and `runtimes/antigravity` are not selected here.
