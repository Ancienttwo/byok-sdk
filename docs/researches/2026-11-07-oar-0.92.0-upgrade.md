# OAR 0.92.0 selected-source upgrade

## Scope and trace

Replace OAR 0.91.0 (`0e9247014498697ed4aaada8a911de68936ffec9`) with the
upstream v0.92.0 release (`6bdd2731dc3ce260db9b3e4804adbaaeca754d83`). OAR
remains selected SDK-owned source, not an npm dependency. Follows #1469; #1492
tracks the upstream items.

The vendor directory moves from `packages/client/vendor/oar/0e92470/` to
`packages/client/vendor/oar/6bdd273/`. Upstream changed 4 of the 112 selected
paths and deleted none. The closure gains `runtimes/dsh/jobs.ts`, which
`runtimes/dsh/projection.ts` now imports: 113 selected files, that is 112 source
files plus LICENSE. 93 keep upstream bytes and the same 19 carry BYOK changes.
`observe/stall-observer.ts` changed upstream and is not selected.

`@agentclientprotocol/sdk` keeps the SDK's exact `1.4.0` pin. Upstream's range
is `^1.4.0` at both versions, and Pi stays `^1.5.0`, so no `package.json` or
`bun.lock` changes.
