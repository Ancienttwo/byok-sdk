# Pi 1.7.0 upgrade evidence

[#2585](https://github.com/Ancienttwo/byok-sdk/issues/2585) pins the ten-package official closure from [upstream v1.7.0](https://github.com/earendil-works/pi/releases/tag/v1.7.0) at `fb0fe823539f6d04850f6e34748c01f01f212e1f`. The closure digest is `e5b5a4a2899b9aaeff0b9e27b43910f7a14bc0a365ffc9538a9288b14c6a6bc5`.

- Before pinning, `collect-official-pi-closure.mjs` verified the registry signatures and matched the SLSA attestations to the upstream tag, commit and downloaded tarball digests. npm's `pacote` verifier also validated the npm publish and SLSA attestations for all ten tarballs. The [closure record](../../packages/client/src/adapters/pi/official-pi-closure.json) retains the provenance bundles and SHA-512 integrities, all of which match `bun.lock`. The workspace install used `--ignore-scripts`.
- The SDK has no callers of the removed install telemetry endpoint, setting, getters or environment switch. Chord 1.7.0 changes named query arguments, remote contract variants and grants, TUI variant helpers, link protocol and the `SyncFileSystem` contract. The SDK uses Chord's context and JSON helpers. It declares no Chord contract or remote query and implements no Chord filesystem. [Coding agent changelog](https://github.com/earendil-works/pi/blob/v1.7.0/packages/coding-agent/CHANGELOG.md#170---2026-11-27) · [Chord changelog](https://github.com/earendil-works/pi/blob/v1.7.0/packages/chord/CHANGELOG.md#170---2026-11-27)
- Every executable file under `pi-durable/dist/storage/sqlite/` is byte-identical to 1.6.1. On macOS arm64 with Node 24.22.3, pi-durable 1.7.0 opened a copy of the 0.47.1 release fixture (written by 1.6.0) and a copy populated with a committed 1.6.1 transcript entry. Both kept the same inode, nine table definitions, `user_version`, and all rows (two and 21 respectively). Both also reopened with 1.6.1. The SDK's existing replica guard therefore needs no migration.
- The generated keys catalog removes three Ant Ling IDs, five OpenRouter IDs, two Together IDs and `qwen4-max-preview` from both Qwen Token Plan endpoints relative to 1.6.1. The OpenRouter Ernie 5.5 Flash preview adds `off`, `low` and `medium`. The provider credential environment list and six hashed Pi HTML-export assets keep their contents. The provider-branch inventory still has 43 rows. The OpenCode Go reasoning field branch now compares `field`, with provider selection still governed by the explicit `opencode-go` projection. The compile graph adds `openai-completions-reasoning.js`, an import-free codec for wire reasoning fields and transcript signatures.
