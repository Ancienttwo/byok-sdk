# OAR 0.33.1 source upgrade

Plan: `plans/plan-20261007-1800-oar-0.33.1-upgrade.md`, commit 1.

## P1 boundary

OAR is private source in the client package. It is not an npm dependency.
The old base is tag `v0.29.0` at `f1a2b88eb63e47de8197514e9329642e2d0ae02c`.
The new base is tag `v0.33.1` at `e1f91770a7edbaf4521f570345f2e8d0c998d238`.
The selected inventory now has 26 TypeScript files and LICENSE.

## P2 runtime path

The path does not change. `CodexAdapter` calls the JS bridge, which exports the
private `codexSession`. The adapter does not pass `mcpServers` yet, so the
open request and the redactor are the same as before. The BYOK event
projection reads native frames, so the upstream resume baseline does not
change BYOK usage events.

## P3 decision

Take upstream bytes. Keep only the BYOK deltas the manifest names.

- `contracts/records.ts`, `contracts/session.ts`, `shared/token-totals.ts`:
  upstream bytes.
- New with upstream bytes: `contracts/session-options.ts`,
  `runtimes/codex/token-usage.ts`.
- New maintained file: `shared/mcp-servers.ts`. `toSorted` (ES2023) becomes
  `sort` on the spread copy, for the SDK ES2022 library.
- `git merge-file` merged the four changed maintained files. Nine conflict
  hunks were resolved: upstream code plus the named BYOK lines. `session.ts`
  builds the open request before the owned spawn, as upstream does.
  `app-server-client.ts` redacts error replies and the BYOK exit error, which
  holds the stderr tail.

## Assertion review

One assertion changes. `oar-app-server-client.test.ts` pins the list of
maintained files. The list gains `shared/mcp-servers.ts`, because the
inventory gains that maintained file. Other tests change only import paths
and the manifest root.
