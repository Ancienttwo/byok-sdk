the Codex session, shared ACP stack, Grok session and process-tree helpers.
The JS bridges and provenance build step select the fork directory.

## P2: Decision and plan

1. Verify upstream tag v0.70.0 and compare every selected source file.
2. Move the fork from 60ad09b to 44d7d61. Keep the eight BYOK-maintained files.
3. Update bridges, source hashes, build assets and current source references.
4. Run the OAR bridge checks, API surface, typecheck and client tests.
