Required candidate changes:

- **#623 / #602 — acknowledged history compaction.** Explicit transactional
  compaction removes eligible acknowledged settled Host history while preserving
  unsettled work, unacknowledged outbox entries, deduplication windows and
  permanent retired intent identities. It does not automatically delete user
  data, bound the total database, or complete outbox limits and memory-row
  compaction. Follow the compaction contract's whole-database backup/restore and
  downgrade restrictions.
- **#642 / #624 — required closing replies.** Preserve the required reply when
  normal runtime completion lacks a usable result outcome. Reply delivery is
  separate from success: retain the canonical task failure and no result
  document; cancellation takes precedence. Recovery retains that decision
  without duplicating the accepted reply.
- **#643 / #628 — fresh Grok persona.** Append the strict Agent's bounded
  canonical-home `AGENTS.md` to fresh-session rules while preserving reader cwd
  and trust authority. Persona-bearing resumes refuse before spawn; this does
  not introduce session replacement or supported resumed persona rules.
  Non-Agent and persona-free resume behavior stays unchanged.

Optional PRs #639, #640, #641, #644, #645 and #646 are **not included**.
The next-batch work listed in #649, including memory restore #632 and Windows
memory admission #605, is outside this candidate. Earlier broader integration
