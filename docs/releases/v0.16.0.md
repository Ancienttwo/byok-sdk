# BYOK SDK 0.16.0 · keys 0.4.2

Published 2026-09-09.

BYOK SDK 0.16.0 adds three public operator APIs for embedded hosts. The nine SDK packages are aligned at 0.16.0; `@byok-sdk/keys` is 0.4.2 with an exact core 0.16.0 dependency.

- `quarantineDeviceOperationalHealth`: reuse SDK-owned health quarantine instead of modifying SDK files from the host.
- `exportDeviceSupportBundle`: export an allowlisted, redacted, bounded support bundle without overwriting an existing destination.
- `archiveAgentTerminalMessages`: archive terminal messages for an explicit Agent, with device/tenant identity validation, device and Agent leases, and durable audit persistence before replacing the live log. Pending/held/draft messages remain live.

The client root exports narrow receipts and closed `DeviceOperatorError` codes. Hosts retain user confirmation, authenticated target selection and service lifecycle ownership. Full terminal archives can contain sensitive message bodies; they are separate from redacted support bundles and are not replay inputs.

This is an additive public API minor release under the pre-1.0 version policy. Pi remains 0.85.1. No new dependency or database migration is introduced by this release. Salesko integration and host deployment remain separate work.

Install: `npm install --save-exact @byok-sdk/client@0.16.0`.
