# BYOK SDK 0.18.0 · keys 0.5.0

Prepared for release; not published. The nine dispatch packages align at 0.18.0.
Independently versioned keys 0.5.0 pins core 0.18.0; Pi remains 0.85.1.

- Strict recurring submission persists one explicit fresh execution contract.
  Hosts must persist the complete validated input before submission and reuse it
  for admission recovery. Cloud and embedded server expose exact message disposition, first-message
  discovery and actual device terminal independently of Host cancellation.
- Selected result documents survive metadata-only Agent egress. Terminal summary
  and activity stay private; Conversation, queue, Summary and retry decisions
  remain Host-owned. Existing explicit session APIs remain separate.
- Pi requires declared model settings and exact profile binding. The installed
  adapter preserves task extension/permission context through credential custody;
  version detection, direct RPC and custody invoke package scripts through the
  interpreter on Windows as well as Unix, without shell or fallback execution.

## Breaking storage boundary

Custom TaskAttemptStore implementations must implement readTaskAgentMessage;
custom embedded attempt stores must provide the corresponding required read.
Update these adapters before adopting this release. There is no private receipt
parser, wire fallback or invented disposition when evidence is missing.

keys 0.5.0 changes its SQLite profile schema. Older stores are rejected and left
intact, not migrated. Preserve the original database and explicitly provision a
separate current-schema store; do not delete history to pass startup. Pi profiles
require authoritative pi_model settings; changed config changes revision/hash,
so export and select a new exact binding before admitting new tasks. Direct
provider transports do not require Pi settings. See packages/keys/README.md.

No Host data migration, live Profile update, deployment, real credential use or
provider inference is part of this release preparation. Salesko ContextPack,
Summary/budgets and production rollout remain downstream acceptance work;
aiphabee is paused. These are not implied by SDK transport/RPC verification.

The RC source passed 4012 tests with 135 skips and 46 CI checks, including native
Windows pack/install on Node 22.22.3. Stable-version CI artifacts and the dry-run
publication plan must match the exact release source; see the release handoff.
