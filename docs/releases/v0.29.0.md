tag or publish. It is a draft. The scope is not complete, and the manifests

exception. Issue #743 states this in its first paragraph:

exceptions. The release adds public API and behavior: the
`@byok-sdk/core/sealed-payload` subpath, `writeHomeFile` on the Agent-home

## Upgrade notes for Hosts

- **Agent memory names.** On every platform, recall, save, intents and
  observation refuse a memory path with a Windows device name (such as
  `notes/con.md`), a segment that ends in `.`, two names below `notes` that
  differ only in ASCII letter case, or a file with more than one hard link.
  Existing notes with these names or links stop being visible to recall and
  export. A `MEMORY.md` with more than one hard link makes capture fail
  (#605).
- **Per-task Agent memory.** The `agentMemory` offer field is a gated wire
  addition. Server and hosted cloud refuse it to a device that does not
  advertise `agent-memory-selection`, before the task exists. So an older
  device gets no task that carries the field. `read` or `read-write` is declined
  when the daemon does not admit the memory MCP; the daemon does not change it
  to `none`. A Host that wants memory only when the daemon admits it sends no
  `agentMemory` (#614).
- **`writeHomeFile`.** The names `.byok`, `MEMORY.md`, `notes` and
  `<file>.<pid>-<n>.tmp` belong to the SDK and are refused. Each call is
  atomic for one file only. On Windows, a successful call has flushed the file
  but not its directory, so an OS crash or a power loss can bring back the old
  bytes; a delivery of the same revision and hash repairs a lost file (#738).
- **keys downgrade.** 0.28.3 and earlier refuse a `pi_model` without a map.
  Before a downgrade, give each such profile a complete map or delete it.
  Otherwise the older SQLite store fails `list()` and each read of that
  profile, and the older truth store fails every read and write of the
  registry (#636).
- **Sealed payload.** `@byok-sdk/core/sealed-payload` is a new subpath. Its
  bundle imports `ByokCoreError` from the root entry, so both entries throw
  one error class. No wire message carries sealed content in this release
  (#654).
- **K8 (example).** The Host refuses a `CollaborationState` version 1 ledger
  with a clear error and writes no migration. Read the CHANGELOG entry for the
  documented behavior changes (#737).
- **Pending (#759): helper assets.** Helper manifest version 2 records the
  digest in each entry. A product directory copied from an older release fails
  with "manifest mismatch", so copy the helper assets again from the SDK
  build. `copySdkNativeAssets({ platform: 'win32', arch: 'x64' })` also copies
  the helper and needs the helper build on the build host.
- **Pending (#761): Windows Agent memory.** Windows x64 admits the memory MCP,
  the hosted projection and `agentMemoryExport` through the SDK helper, on a
  local NTFS volume only. B stays false.
- **Pending (#767, #768):** macOS local volumes and the Windows npm shims,
  if they merge in time.

## Remaining limits

- B stays false for Agent memory (#605). A Windows write is atomic under a
  process crash, but it is not durable after an OS crash or a power loss. The
  power-loss experiment waits for a Windows environment from the owner.
- Real-provider and real Windows Hermes and Grok runs wait for a Windows
  environment from the owner (#608, #609).
- The `submit_result` success rate on real runtimes needs paid calls and owner
  approval for each run (#610).
- No live provider run, real-user memory restore or downstream product
  acceptance is claimed.
