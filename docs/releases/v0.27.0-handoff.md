## P1: release boundary

The package manifests are the version authority. The private workspace root,
conformance and testkit are outside the nine-package publication set.
The changes update the nine versions, the nine Bun workspace records, current
version documents and the first stable v3 corpus entry. Runtime source and
test assertions remain equal to the runtime baseline.

The registry baseline is 0.26.1 / keys 0.11.1 on `latest`, and
0.27.0-rc.2 / keys 0.12.0-rc.2 on `rc`. All nine dist-tag sets were read back
on 2026-10-17. This preparation makes no registry change.

## P2: source to published package

`check:release-graph` checks manifest alignment and the runtime dependency
graph. `check:release-pack` packs the nine packages and installs an isolated
consumer. The schema-3 release manifest records the source SHA, dependency
maps, registry expectations and tarball hashes.

The publisher verifies that manifest against HEAD. A dry run stops before the
account gate, npm writes, post-publication readback and tag creation.
Publication must use the accepted `release-pack-<sha>` artifact from the final
merged commit's successful push CI. Local tarballs prove local packaging;
they do not replace that CI artifact.

## P3: stable and compatibility decision

0.27.0 and keys 0.12.0 are MINOR releases under the pre-1.0 policy. The
runtime baseline has public API, persistence and wire changes. Devices and
the Host must upgrade together because wire v2 and v3 do not interoperate.

The existing protocol test rejected stable 0.27.0 before registration and
printed the exact entry to append. This preparation copies that entry:
157 envelope lines and 17 HTTP lines. No corpus line or assertion changes.
The envelope SHA-256 is
`2f09fc7d7d813903dbd80715ae06e6ef6f8e12f5ed0806b0dcdad619bcf0ff90`.
The HTTP SHA-256 is
`c24f0d3e67aa8712a8f2c5f651363bcc87d62744c0e946122d47dfd39a95e43d`.

After publication, add the registry tarball alias for the published 0.27.0
decoder, set the v3 floor and restore cross-release checks. The 0.26.1 alias
