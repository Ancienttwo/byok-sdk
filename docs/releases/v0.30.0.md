# 0.30.0 — source candidate (in preparation)

This is release preparation, not a publication record or approval to merge,
tag or publish. It is a draft. The scope is not complete, and the manifests
still name 0.29.0. Items marked **Pending** wait for a PR that is not on main
yet, or for an owner decision.

0.30.0 is a MINOR release under the default pre-1.0 policy. Issue #788
states the reason:

> 0.30.0 是 MINOR，按 pre-1.0 规则发：#784 加 gated wire 类型，#782 加公开 API。

In English: 0.30.0 is a MINOR under the pre-1.0 rule, because #784 adds gated
wire types and #782 adds public API. The owner decided on 2026-10-23 that
every open issue and PR is in the scope of 0.30.0. All nine public packages
will move to 0.30.0. Private packages remain unchanged.

Registry state. Recheck before publishing. The published 0.29.0 record is in
the [0.29.0 release notes](v0.29.0.md).

## Upgrade notes for Hosts

This section collects the facts that a Host must act on at the upgrade from
0.29.0. The CHANGELOG check in the preparation PR is the source. Some of these
changes have no CHANGELOG entry yet. **Pending:** the entries, and the PRs that
are not merged yet.

- **Postgres migration 0027.** Apply `deploy/sql/0027_e2ee_member.sql` before
  0.30.0 runs on Postgres. It creates five E2EE member tables. A device
  removal deletes the device rows from three of them, and tenant erasure
  covers all five (#654 E2c-1).
- **`ByokCloud` implementers.** The `ByokCloud` interface gets 13 new
  methods: `redactTasks` (#782), six sealed hosted entries (#784) and six E2EE
  member methods (#828). Code that implements or mocks the interface must add
  them. Code that only calls `ByokCloud` does not change.
- **Activity and approval readers.** `ActivityTail.entries` is now
  `ActivityTailEntry[]`, a union of `TimelineEvent` and `SealedActivityBatch`.
  `ApprovalTimelineEvent` gets a sealed request member with no `summary`.
  `projectTimelineEvents` and `parseTimelineEvents` return
  `ActivityTailEntry[]`. Code that reads `entry.event` or `summary` must
  narrow the type first (#654 E3b-2).
- **Custom task redaction stores.** `TaskRedactionStoreInput` gets the
  required field `releaseObjectReferences`. A Host with its own
  `TaskRedactionStore` must remove those object references before it deletes
  the task's objects. Otherwise the sealed ciphertext of a redacted task stays
  stored (#654 E3b).
- **Custom local task journals.** `LocalTaskJournal` gets the required method
  `appendWithheldOffer`, and `readTask` can return a `WithheldOfferTask`. A
  Host that injects its own journal must implement them. The SQLite journal
  adds the column `withheld_bytes` when it opens. On a journal with a withheld
  offer, an older daemon stalls its cursor when the same task is offered
  again (#826).
- **Sealed numbers.** Sealed content now accepts decimal plaintext numbers
  (RFC 8785). A 0.29.0 opener may refuse a decimal plaintext that 0.30.0
  seals (#786).
- **Plaintext lanes refuse sealed fields.** The plaintext hosted entries,
  the reference server `dispatch()` and `executions.submit`, and the wire
  schema refuse `sealing` and `sealed`. `steerTask` refuses `steerId`. The
  error is `coordination_input_invalid`. Before, these keys were dropped and
  the task ran in plaintext (#654 E3a).
- **macOS mounts below the Agent home.** The helper refuses an entry below the
  home that is on another device than its parent, with `unsafe_path`. Memory
  recall and save, the hosted projection and the task-free export fail where
  they reach such a mount. Move the mount out of the home (#781).
- **`agentMemory: 'read-if-admitted'`.** Server and hosted cloud refuse the
  value to a device without the capability `agent-memory-read-if-admitted`.
  Upgrade the devices before a Host sends it (#815).
- **K8 (example).** `CollaborationState` moves to version 3 and refuses a
  version 2 ledger with no migration. Back up the ledger before the upgrade.
  To roll back, restore that backup or start a new ledger (#798 S2). The
  `BotCollaboration` constructor refuses a Host ledger that was opened
  without `{ compactVeto: botCompactVeto }` (#816).
