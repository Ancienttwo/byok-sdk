## Upgrade notes for Hosts

- **Stateless MCP HTTP.** A `tools/call` with `_meta.progressToken` now gets
  HTTP 400. 0.28.1 had no progress support and did not reject the token. Send
  no progress token in stateless mode, or use stateful mode (#631).
- **Codex deadlines.** One 30 s budget now covers the open: initialize,
  `thread/start` and the read-back. A prompt or steer timeout now ends the
  session and kills the app-server. Before, it rejected only that control.
  `CodexAdapterOptions.operationTimeoutMs` sets the budget (#652).
- **Relocated memory-helper assets.** The SDK checks a relocated helper
  directory against the release identity compiled into the running SDK. Copy
  the assets from the same SDK build that bundles the Host (#603).
- **Wire.** `task.progress` `events[].mcp` is a registered strip-safe wire
  addition. A receiver without the field, such as the published 0.27.0 floor
  decoder, strips it (#633).
