## P1/P2/P3

- 权威入口：`McpToolsetRegistry.buildState` 验证本机定义并冻结；`canonicalServers` 决定 revision。
- 链路：`admitOfferLimits` → `resolveMcpServers` 同次读取 registry，复制 servers 与授权 → `prepareOfferRuntime` 的 descriptor capability gate → `startOfferRuntime` 传 frozen approvals → Codex `beforeOpen` 与固定 helper grant 一次投影 → thread/start 或 thread/resume。
- 约束：不把授权放入 wire、vendor 或 SDK helper server 配置类型；不重读运行中的 registry；不猜工具是否存在；不改其他 runtime 实现。拼错名沿用已验证的 runtime 拒绝行为。
- 最小代价：每次 attempt 复制/排序有限本机名单，开 thread 时投影；不新增进程探测。规模十倍时先增加名单与 thread config 大小，而不是每次工具调用的同步判断；沿用已有 tool-name 形状与本机 toolset/server 数量界限。

## 实现交接（未运行最终检查）
