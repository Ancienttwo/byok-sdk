## Design Decisions

- One SHA-256 deterministic timing authority uses loaded `productId + deviceId`, explicit `reconnect`/`upload`/`maintenance` domains and a non-negative sequence. It has no random fallback.
- Automatic WS reconnect、long-poll failure/stall、outbox upload retry、long-poll→WS probe and hosted storage maintenance consume that authority. `connect({auto:false})` never schedules a delay.
- Operational health is a local-only file (`operational-health.json`, 0600, atomic rename + platform-correct fsync): POSIX flushes target + parent directory；Windows flushes the published target through a writable handle because Node/libuv has no directory-flush API. It carries a 60s/3-failure budget, `healthy/degraded/recovering`, load- and write-bounded failure/crash history and one run marker. The marker starts only after the existing single-owner control bind check, so a rejected second daemon cannot overwrite the live daemon's marker and manufacture a crash.
- Corrupt JSON/shape becomes a normalized `unavailable` snapshot. The file is not deleted, renamed, overwritten or treated as healthy; S7-b owns quarantine/doctor/fix.
- Health events persist only source category and timestamp. Status projects aggregate counts/state/crash timestamp, never error body、prompt、secret or token.

## Deviations From Plan Or Spec

- `ConnectionManager` derives the same deterministic authority itself when constructed directly (test/embedder seam) from its already-required product/device identity; production `createDaemon` injects the shared instance so maintenance and transport use the same seed authority. This is deterministic fail-closed behavior, not a random compatibility fallback.

## Tradeoffs Considered

| Option | Decision | Reason |
|--------|----------|--------|
| Persist every success | reject | a healthy long-poll can succeed every 250ms; fsync on every no-op would create self-inflicted disk load. Only failures and health-state transitions write. |
| Start run marker before control ownership check | reject | a losing second process could overwrite the live run marker and create false crash evidence. |
| Auto-rebuild corrupt state | reject | destroys the only evidence S7-b doctor/quarantine needs and falsely claims healthy. |
