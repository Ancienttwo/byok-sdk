## Design Decisions

- `collectDiagnostics` is the single typed source for doctor and support bundle. It probes runtimes, normalized authenticated-control reachability, read-only health/journal/workspace state and bounded quarantine metadata without importing a write capability。
- SQLite doctor uses `DatabaseSync(..., {readOnly:true})` + bounded `PRAGMA quick_check(1)` only when `node:sqlite` is available. It never constructs `SqliteLocalTaskJournal`, so inspection cannot trigger the production quarantine side effect。
- The only fix requires both `--fix` and `--yes`, refuses while control is online, streams SHA-256 over the corrupt health file, rechecks size/mtime, renames it into the existing never-auto-delete quarantine and writes a digest-bearing manifest. It never rebuilds health/journal state。
- Support bundle projects an allowlist, not a redaction pass over raw objects: config becomes protocol/booleans/counts；identifiers/filenames become SHA-256；audit becomes last 256 KiB / 200 kind+timestamp facts；offline error detail is normalized. Same-directory hard-link publication is atomic/exclusive, followed by target fsync and POSIX parent fsync。
