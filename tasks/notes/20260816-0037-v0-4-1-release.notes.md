## Design Decisions

- Release all eight aligned dispatch packages at 0.4.1 and keep `@byok-sdk/keys` at 0.1.0.
- Keep `task.complete.document` as the single terminal result authority; the release does not introduce the `truth.records` alternative path.
- Freeze final tarballs only after the release PR is merged, from the exact merged source SHA.

## Deviations From Plan Or Spec

- `bun install --lockfile-only` and `bun install --force --lockfile-only` under Bun 1.3.14 both report a saved lockfile but intentionally do not update the informational workspace `version` fields when the dependency resolution graph is unchanged. `bun.lock` therefore remains byte-for-byte unchanged; package manifests and frozen tarball manifests are the release version authorities.

## Tradeoffs Considered

| Option | Decision | Reason |
|--------|----------|--------|
| Publish only changed packages | Reject | It would split the established aligned release train. |
| Publish eight aligned packages | Accept | It preserves one downstream pin and exact workspace dependency translation. |
