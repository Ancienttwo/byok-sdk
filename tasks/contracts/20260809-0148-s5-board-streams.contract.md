## Why

S4B 已完成 durable data plane，但共享 board、SSE/poll 与 bounded hints 仍没有 hosted behavior。若跳过，S3 延后的 I6 未闭环；若做错，会让 device terminal 冒充 human acceptance、stream 跨 tenant，或 unbounded hint 写压拖垮数据面。

## Goal

交付 B-001..B-010：board host/control 与 device coordination surface、CAS conflict snapshot、per-tenant sequence、poll/SSE parity、Last-Event-ID/heartbeat/reconcile/revocation、presence rate+TTL、activity batch+dropped，以及 I1/I6 和 100-way Postgres claim；零 wire/schema/migration drift。

## Scope

- In scope: core hint contract refinement；InMemory/Postgres conformance；cloud tenant facade、capabilities、host methods、board/presence/activity handlers、terminal/progress projection；S5 tests/docs/ledger。
- Out of scope: protocol DTO/golden、SQL migrations、S6 proof/truth、D1/KV/DO、frontend UI、automatic scheduler。
- Taste constraints: no status sniffing/fallback；no second event authority；device cannot write `done`；producer labels bounded and never derived；identity only from authenticated principal/facade。

## Stop Conditions

- Stop if S5 requires changing `packages/protocol/**` or `deploy/sql/**`.
- Stop if SSE requires holding a transaction/leased pool connection across sleep.
- Stop if `done` cannot remain host-control-plane-only.
- Stop if hard dataplane or strict workflow checks cannot run.

## Falsifier

同一 feed behavior suite 分别走 poll/SSE，期间 tenant B 并发变更。A feed 出现 B row、A cursor 被 B 推进、或 reconcile 不能恢复 current snapshot，任一即证伪。
